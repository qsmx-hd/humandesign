LMI Franchise Wheel

LMI 特许经营飞轮

领导管理国际（Leadership Management International）的轻资产规模化模型——人类图领导力课程最该抄的「飞轮结构」对照标杆。

⚠️ 先澄清：特许经营 ≠ 直销 / 传销

常被中文语境混为一谈，但两者本质不同：特许经营是授权方把「品牌 + 成熟商业模式 + IP」许可给被授权方，后者在自己地盘独立经营一家本地企业、向企业客户卖服务赚钱，再向总部交加盟费 + royalty；直销 / 多层营销（MLM，如安利、玫琳凯）则是个人销售代表直接向消费者卖货、靠层级返利抽成。LMI 连续 7 年登《企业家》杂志 Franchise 500（特许经营 500 强）——这是加盟榜，不是直销榜。

飞轮怎么转（六步闭环）
1

低门槛加盟

~$2 万总投资、可家庭办公 / 兼职，吸引大量本地创业者成为加盟商。

↓
2

加盟商替总部承担获客

加盟商去本地企业卖 B2B 培训（自己找客户、自己交付），总部不养直营销售团队。

↓
3

总部收「授权 + royalty」

加盟商交初始加盟费（约 $15,000）+ 持续 royalty 6% + 教材 / IP 授权费，轻资产收租。

↓
4

训练出 measurable 结果

多感官课程系统（EPP / EPL / EML / ESL）带来可衡量改变，客户有体感、愿续费。

↓
5

复售率 >50%

英国数据：老客户复售率超 50%。加盟商赚到钱、口碑扩散，网络自我生长。

↓
↻

飞轮加速（回到第 1 步）

加盟商赚钱 → 扩区 / 续约 → 更多加盟商加入 → 网络越密、总部 IP 成本越摊薄、越值钱。

加盟结构（标准特许经营）

创立与规模

1966 年 Paul J. Meyer 于美国德州 Waco 创立，400+ 加盟点（美国 100+），特许经营始于 1966 年。

区域独家权

加盟商买的是区域独家经营权（exclusive territory），在自己地盘独立做生意，不与总部抢客户。

费用结构

初始加盟费约 $15,000（来源区间 $9.5k–$25k）；总投资 $20k–$27.5k；royalty 6%。

合同与续约

合同期 5 年、可续约；低 overhead，多数加盟商家庭办公、可兼职起步。

总部给加盟商什么
支持项内容
培训40 小时培训 + 导师（mentor）一对一陪跑
物料视频 / 手册 / 专有软件 / 多感官课程系统
获客客户开拓方法、销售组织建设（franchise build-up）
社群区域会议、全球加盟商网络互通最佳实践
与麦当劳同构：麦当劳不靠直营餐厅赚钱，靠品牌授权 + 抽成；LMI 不靠总部顾问飞到企业做项目，靠 IP 授权 + royalty 躺着收租。核心都是——把获客与交付成本甩给本地节点，总部轻资产规模化。

💡 对你的可借鉴点（人类图 HD-L / HD-C）

你做 HD-L / HD-C 认证课程（IP 在总部）→ 认证出的教练 / 内训师成为你的本地合作节点，去各自企业客户交付 → 你收认证费 + 教材 / IP 授权 + 网络续费（类 6% royalty）→ 他们拿「可收费接个案 / 企业内训」身份赚钱，同时替你完成市场下沉与获客。这比 CCL / DDI 那种「总部顾问飞企业做项目」轻得多、可规模化得多，且与你报告里的「教练认证体系 + 实践圈」天然同构。
