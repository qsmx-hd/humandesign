THE DUAL HELIX

人类图是出厂设置，七个习惯是操作系统

市面上的课程大多止步于「知道」：知道自己是投射者、知道要积极主动。
但知道设计，不等于活出设计；读完习惯，不表示改了行为。真正的效能，是让两者在每日练习里汇合。

知 · 人类图效能地图

📐 它告诉你「你的效能长什么样」

  • 类型与策略：你与世界正确互动、正确「用力」的开关（生产者 37% / 显示生产者 33% / 投射者 21% / 显示者 8% / 反映者 1%）
  • 内在权威：身体的决策系统，效能的第一道闸门
  • 成熟模式图：你的设计指明，你在依赖期 / 独立期 / 互赖期天然的位置与节奏
  • 非我主题：偏离设计时的效能红灯（挫败 / 愤怒 / 苦涩 / 失望）
  • 去条件化：放下「别人教你的努力方式」，回到自己的设计
行 · 七个习惯

🗝️ 它教你「如何修炼效能操作系统」

  • 思维定式与由内而外：改变行为之前，先看「你看世界的眼镜」
  • 个人成功三习惯：积极主动（影响圈）· 以终为始（使命宣言）· 要事第一（时间矩阵）
  • 公众成功三习惯：双赢思维（双赢协议）· 知彼解己（移情聆听）· 统合综效（第三选择）
  • 不断更新：身体 / 精神 / 智力 / 社会情感，四个层面磨锯
  • 付诸行动：每个习惯都配柯维原书的落地练习，知行结合
🌉 效能之道，就是让人类图从「出厂设置」变成「高效能人生」的那一座桥——活出设计 × 修炼习惯，由内而外

CORE MODEL

类型 × 效能转化 · 效能红灯 → 顺流状态

人类图的非我主题，就是「偏离设计、效能卡住」的状态；活出设计，习惯才修得动。
当效能红灯亮起，先回到策略权威，再用对应的习惯把它转回顺流。

WHO IS IT FOR

这门课，适合这样的你

无论你是人类图老手还是刚入门，只要你想「顺着自己的设计变高效」而非「逼自己复制别人的自律模板」，这里就有你的位置。

📖

读过七个习惯却没改变的人

道理都懂，一到工作生活就回到老模式。你需要的是把练习接进自己设计的方法。

🗺️

读懂图却活不出的人

知道策略权威，一忙起来就硬干硬推。用成熟模式图定位卡点，练习里慢慢松开。

⚙️

长期「很忙很低效」的人

被第一、三象限追着跑。用时间矩阵 + 能量管理，把要事放回第一位。

🤝

管理者 / 团队负责人

情感账户、双赢协议、统合综效——把公众成功三习惯变成团队语言。

💡

人类图解读师 / 分析师

从「解读类型」升级到「陪伴成长」，学会用七个习惯陪客户把设计活成日常。

🌱

想持续精进的人

不满足于鸡汤与技巧，想要一条能落地、可自检、日日更新的「由内而外」之道。

LEARNING PATH

两条学习路径

效能之道不是听明白的，是练出来的。给自己一个小目标，先坚持起来。

🌤️ 21 天效能入门

每天 10–15 分钟 · 觉察·练习·行动 三层打卡
  • 建立「每日效能觉察」的基本节奏
  • 认出自己的非我·效能红灯触发点
  • 写出一句专属使命宣言并天天念
  • 用时间矩阵完成一次「第二象限周计划」
  • 完成 21 篇效能觉察日记

🌳 100 天高效能扎根

把练习变成呼吸 · 口诀：「由内而外，先设计，后习惯」
  • 从「工具式修行」走向「在生活中练习」
  • 七个习惯逐个稳定落地（附柯维原书练习）
  • 在等待 / 告知 / 回应中自然对齐设计
  • 建立情感账户与双赢协议的人际系统
  • 迈向「身体·精神·智力·社会情感」四层面更新
