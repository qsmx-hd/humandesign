底层核心方法论（统一训练内核）
所有销售与主管训练都围绕两大方法论展开：NBS 需求导向销售（卖家庭财务安全，不卖产品）与 MET 主管辅导五环（每周固定的管理动作闭环）。下面是可落地的执行细则。
一、NBS 需求导向销售（Needs Based Selling）

核心理念

  • 先诊断需求、后匹配方案；卖财务规划，不卖保险产品
  • 以家庭现金流、风险缺口为沟通主线，不谈收益、不先讲条款
1. 建立信任与面谈定位（破冰）
开场即定位“财务规划顾问”，先梳理风险而非推销
  • 收集家庭结构、职业、收支、负债、已有保障、家庭责任
  • 控制自我表达，多用开放式提问；3 分钟内建立安全感
  • 通关标准：客户愿意配合完成信息问卷
2. 需求发掘（结构化提问 · 核心）
四大风险维度：收入中断 / 医疗大额 / 养老现金流 / 传承教育
  • 漏斗式提问：宽泛 → 聚焦痛点 → 量化损失
  • 引导客户自己算出“风险→现金流断裂→目标落空”的缺口
  • 禁止替客户定义风险，必须让其自我感知
3. 需求分析与缺口量化
  • 录入财务分析系统，测算家庭责任额度（负债/抚养年限/月度开支）
  • 现有保障额度抵扣，得出保障差额
  • 方案额度由缺口推导，预算仅用来调整结构（保障/储蓄配比、缴费期）
4. 解决方案设计
  • 基础保障层优先：寿险 / 重疾 / 医疗 / 意外覆盖突发风险
  • 长期目标层：教育金 / 养老金 / 资产传承
  • 组合方案，不单一产品堆砌；备 A 方案（标准缺口）+ B 方案（预算折中）
5. 方案呈现与建议书讲解
  • 顺序：家庭责任 → 风险后果 → 缺口大小 → 规划方案 → 产品作用
  • 严禁开篇直接演示产品利益表
  • 异议处理统一逻辑：回到客户家庭需求，不陷入产品利益对比
6. 促成 · 递送 · 持续经营与转介绍
  • 促成落脚点：完成家庭财务安全目标，而非“买一份保险”
  • 建立每年保单检视机制，递送不是服务终点
  • 标准转介绍问话：身边同样承担家庭责任的亲友，是否也需要一次免费财务梳理？

NBS 配套落地保障

  • 统一制式财务问卷、标准化建议书模板
  • 新人必须全流程角色扮演通关，未通关禁止独立面谈
  • 主管 ODC 陪访重点检视：是否跳过需求挖掘直接讲产品
  • 质检录音核查 NBS 流程，杜绝产品导向推销
二、MET 主管辅导五环（Management Effectiveness Training）

通用前提

  • 五环是每周固定循环的管理动作，主管最低标准工作循环
  • 教练模式：多提问、少命令，赋能自主思考而非直接给答案
RSP · 周计划检视（五环起点）
  • 本周复盘：业绩/访量/成交/转化/准客户/增员，对比计划找差距
  • 下周量化目标：有效面谈≥8、新增准客户5、沙龙2场、增员面谈1
  • 障碍识别纳入 SID / ODC 课题；代理人主动承诺，主管明确配套支持
  • 红线：只盯保费不追访量、单向下达目标、无书面追踪
SID · 个别发展面谈
  • 一对一深度教练，解决个性化能力短板
  • 四步：事实陈述 → 探寻感受 → 共因（意愿/技能）→ 改进行动 + 跟进
  • 场景：新人不出单、绩优瓶颈、增员无果、动作变形
  • 重在启发，多用提问引导自我反思
SGD · 团体发展研讨
  • 小组集中训练，批量解决共性技能问题
  • 流程：课题选取 → 案例导入 → 技能示范 → 两两演练 → 互评 → 课后实战
  • 频次：常规每周≥1次，60–90分钟；新人组提高频次
ODC · 市场陪同展业（最高权重）
  • 示范陪访（新人）：主管主导演示标准 NBS，离场即复盘
  • 观测陪访（有基础）：代理人主导，主管带观察清单记录偏差
  • 硬性标准：新人前 6 月保证频次；禁止“只跟着不辅导不复盘”
  • 陪访记录录入系统，作为主管考核与新人留存核心指标
实战执行闭环（五环串联）
  • RSP 发现共性问题/个体短板 → SGD 团体演练 / SID 一对一
  • 技能学习后 → ODC 市场实战检验纠偏 → 下周 RSP 再检视，持续循环

MET 五环的两大应用场景

  • 销售辅导：NBS 落地、访量管理、面谈技能、客户经营
  • 组织发展：复用五环，内容换为招募面谈 / 新人甄选 / 团队经营 / 主管培育
  • 优秀主管同时用五环做“业务辅导 + 组织发展辅导”

        企业文化是组织发展飞轮（优增优育）的“精神底盘”——清晰的企业愿景、使命与价值观，是吸引同频候选人的底层磁力，也是新人留存与团队凝聚的长期黏合剂。
        企业愿景 · 使命 · 价值观

        企业愿景

        成为客户与社会最值得信赖的保障与财富守护者，让每一个家庭在风险来临时都有可依靠的肩膀。

        企业使命

        • 以专业与温度，帮中国家庭规划可落地的财务安全方案
        • 为每一位代理人提供“凭专业获得尊重、凭努力获得回报”的事业平台
        • 把保障的确定性，传递给更多曾经被忽略的普通家庭

        核心价值观

        • 客户至上：先解决客户的问题，再谈自己的业绩
        • 专业立身：用 NBS 方法论与持续训练，建立不可替代的专业度
        • 长期主义：保单递送不是终点，是长期服务的起点
        • 诚信合规：合规是底线，口碑是最贵的资产
        • 共生共荣：主管与团队、公司与代理人，在双飞轮里彼此成就

        反哺优增：文化即吸引力

        清晰的愿景、使命与价值观，是向候选人传递“这是一份有意义、能长期做的事业”的最佳语言；当候选人与文化同频，留存与自驱力都会显著提升。

        荣誉体系是组织发展飞轮（优增优育）的“加速器”——绩优文化、行业典范与国内国际荣誉标准，既给代理人以尊严与目标感，也是向候选人展示“这份事业的天花板有多高”的有力素材。
        公司绩优文化 · 行业典范

        公司绩优文化

        • 以“持续达标、长期经营”为荣，而非单月冲量
        • 季度/年度荣誉表彰、高峰会议、绩优俱乐部等荣誉载体
        • 把优秀代理人的真实成长故事，沉淀为团队可复制的标杆

        行业典范文化

        • 以行业最高服务与专业标准为镜，建立代理人的职业尊严
        • 合规经营、客户利益优先，做“被社会尊重”的保险从业者
        国际荣誉体系（进阶目标）

        MDRT · 百万圆桌

        • 全球寿险业公认的绩优标准与荣誉组织
        • 以保费、佣金或收入达标，分会员 / 内阁 / 顶级三档
        • 代表专业的“入场券”与持续经营的标杆

        IDA · 国际龙奖

        • 华语地区保险从业者的重要荣誉（国际龙奖）
        • 表彰业务品质、专业与服务兼具的杰出代理人

        CIA500 · 保险名家

        • 以“保险名家”为标准的高绩效团队/个人荣誉
        • 强调可持续的产能与团队经营能力

        其他里程碑

        • 公司高峰会、区域绩优俱乐部、终身荣誉会员等
        • 荣誉路径：新人达标 → 公司荣誉 → 国际荣誉（MDRT / IDA / CIA500）

                  目前我国保险代理人（包括专属代理人和中介公司代理人）对寿险业保费收入的贡献超过50%。作为各公司保险代理人管理的基本纲要，保险代理人基本管理办法（基本法）通过对保险代理人的约束与管理，对公司经营目标的实现产生重要影响。本文对26家公司的基本法内容进行拆解整合，形成包含7个一级指标，30个二级指标，76个三级指标的基本法指标体系。运用层次分析法，在对保险公司管理人员、保险代理人和消费者调查的基础上，确定了指标体系权重，形成了基本法评估框架。基于这一框架，本文聚焦寿险公司经营中重点关注的业务规模、业务稳定性和保险投诉指标，阐述了基本法指标模块与寿险公司经营指标的传导机制，帮助寿险公司基于公司发展目标形成差异化且有针对性的基本法改革思路。
