人类图领导力 · 出生数据出图测评 V6

输入精确出生数据 → 调取 Human Code 完整图 API → 输出你的 4 个核心行星（个性太阳/地球 + 设计太阳/地球）→ 卦象 + 爻线。

源自全球公认的人类图实践体系，遵循「成熟框架为体、人类图为用」的领导力课程定位。

① 出生数据

越精确，爻线越接近你本人。请用 24 小时制填时分。可选填城市（用于自动选时区）。

② 你的 4 个核心行星

个性太阳 = 你今生「有意识」展现的主题 · 个性地球 = 与之对冲的「人格锚点」。
设计太阳 = 你天生「无意识」的健康状态 · 设计地球 = 与之对冲的「身体记忆」。
🛡️ 精度说明：本工具仅输出 4 行星 + 卦象爻线，与正式人类图软件（Jovian Archive / myBodygraph）的 13 行星全图相比省略月亮、水星、金星、火星、木星、土星、北交、南交等次要行星。如需 9 中心定义、36 通道、类型与权威的完整计算，请使用上述专业工具或人工解读。

③ 类型策略 + ④ 内在权威 + ⑤ 人生角色 Profile

M1 · 类型与策略 = 你的领导本色

认识你的设计：类型决定你的「领导动作」，策略是你与世界互动的正确方式。
请先在上方选择或确认你的「类型」，再点「生成报告」。

M2 · 内在权威与决策力

用「时中 / 持经达变」对应你的权威——在正确的节奏里做决定，才是真领导。
请先在上方选择或确认你的「内在权威」，再点「生成报告」。

M3 · 人生角色 Profile = 你活成的样子就是别人的路

认识你的「舞台方式」——领导力不只是做什么，更是「用什么样的身段做」。
请先在上方选择或确认你的「人生角色 Profile」，再点「生成报告」。
🛡️ 原型边界声明：本工具为首门课《人类图领导力》M1/M2 的教学体验原型。4 行星图通过授权 API 实时计算；类型/权威解读由教研团队预先编写并由你的正式人类图作为校准。本工具不替代专业人类图解读，亦不构成任何医学/心理/职业建议。
