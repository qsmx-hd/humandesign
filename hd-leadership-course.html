Course Development Blueprint · V2

《人类图领导力》课程开发蓝图

由全球顶尖人类图体系 × 领导力教练双视角开发。用东方智慧开篇、用你的基因收口

——全球首个「人类图 × 领导力 × 易经」三融合的领导力训练体系。

开发总纲：不替代成熟领导力训练，而是「成熟框架为体、人类图为用」——用 CCL / 富兰克林柯维 / LMI 的"行为科学 + 可量化结果"保公信力，用人类图的"个性化 + 能量层"做差异化，用易经做中国学员的文化入口。训练有效性以 Toastmasters 式「高频练习 + 同伴反馈 + 渐进认证」闭环为骨架。

1课程定位与差异化护城河

先想清楚"我们不做什么、我们唯一占什么位"。
一句话定位：《人类图领导力》= 一门教领导者「先活出自己的设计，再带出团队的合力」的体验式训练课。它不教通用管理技巧，而教"对你这个特定能量构造，什么领导方式才真正有效"。
护城河 1

能量型领导力（蓝海）

头部品牌都做"行为/能力"，没有任何一家从"能量类型 + 决策权威"讲领导力。这是你的稀缺占位。

护城河 2

抗倦怠变现

用"非我主题 / 亢龙有悔"把抽象倦怠变成可操作的能量管理，直击 DDI 数据里 71% 高压、40% 想离职的痛点。

护城河 3

组织设计地图

用类型排布 + 按类型授权 + 会议设计，产出可落地的"团队设计诊断"，企业端高客单。

护城河 4

东方 + 个性化

易经做文化桥、人类图做个人体。CCL/DDI/LMI 均无此交叉位，且最贴合中国企业市场。

与「人类图教练课」的辨识度（避免互抢）：教练课 = 第三人称、非指导、陪个体找自己（1:1、出口 HDCC 认证）；领导力课 = 第一人称、要拍板、带团队出绩效（团队、出口 HD-L 认证）。两者受众几乎不重叠，且可设计为「领导 → 教练」升学导流。

4模块详细设计（M0–M10）

每个模块含：目标 · 人类图知识点 · 领导力落点 · 训练练习 · 时长 · 评估。
M0易经智慧与领导之道（开篇 · 文化入口）
模块目标用中国学员熟悉的语言降低陌生感，建立"领导力是修为"的认知框架。
HD 知识点无（纯文化桥）；为后续"类型=你的领导本色"埋伏笔。
领导落点三易（变易/简易/不易）→ 持经达变；乾坤阴阳 → 刚柔并济；时中 → 决策节奏。
训练练习① 画出自己团队的"爻位金字塔"（谁在几爻）；② 分享一个"亢龙有悔"的真实教训。
时长 / 评估90 分钟线上 + 1 次小组分享 / 提交"我的位与势"一页纸。
设计要点：此处不碰人类图术语，纯讲东方智慧；待学员被"说到心坎"后，再导入"你的设计"——转化阻力最小。
M1认识你的设计：类型与策略（L1）
模块目标学员能准确说出自己的类型、策略、内在权威，并识别其在团队中的领导风格。
HD 知识点5 种类型与策略：显化者(告知)/生成者(等待回应)/显化生成者(等待回应)/投射者(等待邀请)/反映者(等待 Lunar)。
领导落点显化者=发起破局型；生成者=执行持续型；投射者=顾问赋能型；反映者=感知节律型。
训练练习① 画自己的"类型卡"；② 小组"类型觉察互评"(Toastmasters 式同伴反馈)；③ 微练习：一周按自己策略决策并记日志。
时长 / 评估90 分钟线上 + 1 周实践 / 类型卡提交 + 实践日志。
设计要点："类型=你的领导本色"是整门课锚点，须让学员有"被读懂"的体检感。
M2内在权威与决策力（L1）
模块目标学员掌握用自己的内在权威做决策，提升决策质量与速度。
HD 知识点情绪/ sacra/ 脾/ 直觉/ G 中心/ 无权威(反映者) 等 7 类内在权威及其决策节奏。
领导落点用"时中 / 持经达变"对应权威——投射者待邀请、反映者等周期，避免"硬拍板"的内耗。
训练练习① 决策日志(记录每次重大决定用的是头脑还是权威)；② 同伴互查"你的决策陷阱"。
时长 / 评估90 分钟 + 2 周决策日志 / 提交"我的决策节奏说明书"。
设计要点：这是抗"非我决策"的核心，直接对接 DDI"仅 29% 员工信任上司决策"的痛点。
M3人生角色与领导位势（L1·L2）
模块目标用 Profile(人生角色)理解自己在组织中的"位与势"，减少错位焦虑。
HD 知识点12 种 Profile(如 1/3 研究者·烈士、2/4 隐士·机会主义者、4/6 机会主义者·角色模型等)。
领导落点爻位·时位 → "在其位谋其政"；角色模型(4/6)不必 early prove，烈士(1/3)靠试错成长。
训练练习① 把团队画成"爻位金字塔"；② 写"我在组织的真实位势 vs 我以为的位势"。
时长 / 评估75 分钟 / 提交团队位势图 + 个人反思。
设计要点：与 M0 易经爻位呼应，形成"东方框架→个人设计"的闭环。
M4能量中心与领导盲区（L2）
模块目标识别定义/未定义中心带来的"强项"与"盲区"，做好精力管理。
HD 知识点9 大能量中心；定义=稳定能量，未定义=开放吸收/易过载；如未定义 G 中心→方向感外求。
领导落点阴阳平衡 → 定义中心(阳·动)与非定义(阴·容)；未定义中心是"共情雷达"也是"耗竭点"。
训练练习① 标出自己的中心图；② 同伴互评"你的能量盲点在哪次会议爆发"。
时长 / 评估90 分钟 / 中心图 + "我的精力管理协议"。
设计要点：精力管理是抗倦怠的前置，直接服务护城河 2。
M5非我主题与抗倦怠（L2）
模块目标识别"非我主题"(背离本性的代价)，建立可持续的领导节奏。
HD 知识点各类型的非我主题：显化者=愤怒(被阻)、生成者=挫败(错的事)、投射者=苦涩(误认)、反映者=失望(环境)。
领导落点亢龙有悔 / 盈不可久 → "过犹不及"；用东方语境让学员接纳"不是我自己"的消耗。
训练练习① 写"我的非我触发清单"；② 设计"每周能量复位仪式"(如反映者 Lunar 复盘)。
时长 / 评估90 分钟 + 21 天复位打卡 / 非我清单 + 复位计划。
设计要点：本课程最易出"aha"与口碑的模块，也是企业端高复购入口。
M6通道闸门与天赋领导（L2）
模块目标把天赋通道转化为可表达的"领导优势"，而非埋没或过度透支。
HD 知识点36 条通道与闸门含义；定义通道=天赋资产，未定义=可学可借的学习力。
领导落点易经"各正性命"→ 让对的人在对的位置发光；团队天赋互补而非整齐划一。
训练练习① 标出自己的定义通道；② 小组"天赋互见"——别人眼中你的通道如何助力团队。
时长 / 评估90 分钟 / 天赋卡 + "我的领导优势一句话"。
设计要点：人类图"借易经闸门意象"在此显化——可点出闸门与卦象的文化关联(点到即止)。
M7团队设计地图（L3）
模块目标为真实团队产出"设计地图"，按类型排布角色、授权与会议。
HD 知识点团队类型分布诊断；投射者适合顾问位、生成者扛执行、显化者破局、反映者做感知复盘。
领导落点爻位→排兵布阵；按类型授权(投射者需先被邀请再建言)；按类型设计会议节奏。
训练练习① 导入自己团队 3–8 人出生数据出图；② 产出"团队设计地图 + 授权清单"。
时长 / 评估半日工作坊 + 2 周落地 / 提交团队设计地图(企业端可收费交付物)。
设计要点：护城河 3 的兑现点，企业内训的"高客单钩子"。
M8组织设计与文化（L3）
模块目标把个人设计升维到组织动力与文化建设(轻量应用层，不重教 BG5/OC16 机制)。
HD 知识点BG5/OC16 概念掠影(作为"顾问视角"引子，深度留给教练课)，聚焦"组织也有类型"。
领导落点文化=集体非我主题的抵消系统；用设计视角诊断组织瓶颈与继任。
训练练习① 用"组织类型"框架复盘自家公司；② 写"文化修正 3 条"。
时长 / 评估半日工作坊 / 组织诊断一页纸。
设计要点：明确"BG5 深讲是教练课地盘"，领导力课只做应用层，避免与教练课打架。
M9真实领导与仆人式领导（L3·L4）
模块目标把"活出设计"升华为"以德服人"的真实领导，重建团队信任。
HD 知识点无新增术语；综合前 8 模块，落到"真实(authentic)领导"。
领导落点谦卦"修己安人 / 德位相当"→ 真实领导、仆人式领导；六爻皆吉的谦是管理本质。
训练练习① 写"我的领导宣言"(基于真实设计，非抄模板)；② 同伴互评真实性。
时长 / 评估90 分钟 / 领导宣言 + 同伴认证。
设计要点：收束全课——从"读懂自己"到"成就他人"，呼应易经修己安人。
M10毕业项目：设计驱动领导实验（L4）
模块目标学员在自家组织落地一项"设计驱动"的领导实验，量化交卷(类 Toastmasters 顶点项目)。
HD 知识点综合应用：选一个痛点(决策/授权/倦怠/团队)用设计视角重构。
领导落点70-20-10 的"10"实践；用前测/后测数据证明"图真的有用"。
训练练习① 立项(假设+指标)；② 8 周实验；③ 路演答辩 + 同伴评审。
时长 / 评估8 周 + 答辩 / 项目报告 + 数据对比(达标获 HD-L4 认证讲师资格)。
设计要点：这是"训练有效性"的终局证明，也是课程自有结果数据的采集口。

5训练有效性设计 · 七步闭环

你特别强调"训练的有效性"——以下七步直接对标头部品牌的"可量化结果 + 行为科学 + 持续陪伴"。
1

基线测评

入学即出个人设计图 + 领导力前测(决策质量/团队信任/倦怠度)。

2

具身练习

每个模块配"微练习"，把图上的认知变成身体记忆。

3

70-20-10 实验

10% 课堂 + 20% 同伴 + 70% 真实工作实验(毕业项目即此)。

4

实践圈陪伴

Toastmasters 式「HD 实践圈」周例会，按类型布置练习、同伴反馈。

5

问责机制

1:1 督导 + 同伴问责搭档，未完成练习进"复练组"。

6

混合交付

线上自学(图/理论) + 线下实践圈 + 企业工作坊，降低门槛。

7

量化追踪

后测对比前测，产出"我的领导改变报告"，数据回流课程迭代。

6HD 实践圈运营（Toastmasters 式）

HD × TM =「个性化实验室」：TM 给"怎么做训练才有效"的骨架，HD 给"练什么才对每个人有效"的内核。

角色按类型分配

显化者=发起破冰；生成者=执行推进；投射者=顾问复盘；反映者=感知调频。让圈内角色本身成为练习。

周例会与微练习

每周 60 分钟：分享本周"按设计领导"的一件小事 + 同伴即时反馈(类型觉察互评)。

渐进认证

HD-L 四级 + 毕业项目答辩，类 DTM 式里程碑，制造持续进阶的"游戏化"动力。

安全实验室

比 BetterUp 便宜、比企业大班课有温度的黏性社群，是复购与转介绍的发生地。

7认证与升学路径（领导 → 教练）

同一批用户从一门课拉长到两门课，做成可相互导流的生命周期飞轮。
潜在学员池
管理者 / 创业者 / 团队长 · 100%
HD-L 领导力认证
带好自己团队 · 82%

8交付形态与课时安排

按"引流 → 转化 → 规模化"分层，适配个人与企业两类市场。

入门工作坊

1–2 天 · 引流

体验式：出图 + M0/M1/M5 精要 + 一次非我觉醒。低价或企业内购，转化到深度营。

深度实操营

8 周 · 转化

线上自学 + 线下实践圈 + M1–M9 全模块，含团队设计地图工作坊。主利润池。

认证讲师营

12 周 · 规模化

HD-L4 路径 + 毕业项目答辩，产出可独立授课的认证讲师，构成加盟/合作节点。

企业内训 / 授权

定制 · B2B 放大

团队设计地图 + 组织诊断，按企业规模收费；认证讲师下沉交付，总部收授权+续费。
