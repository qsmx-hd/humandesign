人类图教练  vs  人类图领导力

一页对照 · 两门课的辨识度与互补关系

🟤 向内 · 陪你找到自己
VS
🟠 向外 · 带出团队合力

一、教练技术 vs 领导力：本体就不同

两者常被混谈，是因为现代领导力包含"教练式领导"。但本体清晰：教练是一种关系姿态（激发客户自己的答案），领导是一种影响功能（动员一群人朝目标前进）。你可以教练式地领导，但不能在领导时完全教练式——有些决定必须你拍板。

维度教练技术 Coaching领导力 Leadership
本质通过对话 + 提问，激发客户自己的觉察与行动；教练是"过程"专家通过方向与影响，动员一群人朝共同目标前进；是一种责任
核心姿态非指导：不替客户给答案，客户是自己问题的专家可指导：该拍板拍板、该给方向给方向、对结果负责
作用单位主要个体（1:1）群体 / 组织
交付物客户的清晰、承诺、行为改变团队绩效、文化、结果
时间性常围绕目标 / 转折，阶段性持续、系统性

二、两门课的辨识度：三轴拆法

两门课都用到"类型 / 权威 / 剖像"，真正的辨识度来自主语与姿态。沿七个维度拉开：

主语 / 视角
教练第三人称：我作为教练，服务"他"的客户
领导第一人称：我作为领导者，经营"我"的团队
给不给答案
教练不给——提问、陪伴，陪客户自己走出来
领导给——做决策、定方向、对结果负责
改变单位
教练个体觉察与转化
领导团队 / 组织绩效与合力
人类图用法
教练把图当"客户的地图"，教练陪走
领导把图当"自己和团队的操作系统"，用来带人
受众身份
教练想助人 / 已是教练、咨询师、解读师、OD 顾问
领导在带人、有团队的管理者 / 创业者 / 团队长
出口认证
教练人类图教练（HDCC 四级，可收费接个案）
领导更符合设计的高效领导者（HD-L 四级 + 实践圈）
训练形态
教练1:1 督导、个案演练、毕业案例分析
领导实践圈 / 团队实验室（Toastmasters 式）、组织设计项目
辨识度最强的一句话 🟤 HD 教练 =「向内 · 陪你找到自己」（非指导、1:1、个体转化）
🟠 HD 领导力 =「向外 · 带出团队合力」（指导、团队、绩效结果）
一个 HR 想转型做教练 → 上教练课；一个部门经理想带好团队 → 上领导力课。受众几乎不重叠，这是最硬的辨识度。

三、必须处理的"内容重叠"——BG5 / 团队模块

教练课 L4 / BG5 已碰"团队 / 领导力发展"。三条边界即可干净划界，互不打架：

① 领导力课只做"应用层"

不重教 BG5 / OC16 机制（那是教练课地盘），而假设领导者已自知其设计，聚焦决策矩阵、按类型授权、按类型设计会议、抗倦怠节奏、团队角色排布。

② 教练课 BG5 标"顾问视角"

教练课的 BG5 模块明确标注为"以教练 / 顾问身份服务组织"——与"领导者第一人称经营"区分开，视角不同，内容不冲突。

③ 设计成互补 + 进阶

管理者先上 HD-Leadership 带好团队；想转型做教练 / 顾问者，再上 HD-Coaching。两门课互相导流而非互抢。

四、互补升学路径（互相导流）

1
入口：管理者
先修 HD-Leadership，带好现有团队、活出自身设计
2
想进阶助人
若想"助人 / 对外收费"，续修 HD-Coaching，把带人经验转化为教练能力（ICF 八项能力 + HD-COACH 模型）
3
毕业出口
HD-Leadership 出"高效领导者"，HD-Coaching 出"可收费人类图教练"——两条认证链独立、数据互通，形成课程矩阵而非两门孤立课
价值既守住辨识度，又把同一批用户的生命周期价值从一门课拉长到两门——这是单门课做不到的。

五、品牌视觉辨识建议

在统一棕金体系内，用副色强化两门课的视觉区隔（具体由你定）：

🟤 HD 教练

深棕沉静 + 金紫点缀——传递"向内、陪伴、静水深流"。

🟠 HD 领导力

赤陶 / 琥珀活力——传递"向外、行动、带团队出结果"。
