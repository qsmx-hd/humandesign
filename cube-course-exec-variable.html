COURSE BLUEPRINT

高管变量深度解读
Executive Variable Decoding

副标题 · 决策环境设计 ——
把人类图 Variables 四变量，翻译成高管当天就能用的「决策环境设计」语言

6 模块 · 2 天旗舰工作坊 + 21 天陪跑
POSITIONING

课程定位

一句话
把人类图 Variables 四变量，翻译成高管当天就能用的「决策环境设计」语言——身体给动作、心智给看见，不谈命理、不谈改命、不给健康建议。
受众
企业决策者（C-level / 中高层）、HR / OD 负责人、教练与组织顾问。无需人类图基础。
差异点
不靠「神秘感」卖课，靠「可验证、可落地」取胜。用国际通用名 Variables 双轨命名，便于学员交叉验证。
与时下同类课的关系
内容构件同源（Variables / PHS 落在 IHDS L4 层），但本課不自称「魔方矩阵 / Cube Matrix」主品牌，也不宣称官方授权。
「决策环境设计」为什么是副标题 环境（Environment）是四变量里唯一客户当天就能验证、成本最低、见效最快的一项——它直接对应「办公空间 / 远程配置 / 会议与物理协作模式」。把整门课框定为「设计你的决策环境」，是以最可执行的杠杆（物理空间）为锚，再带出信息节奏、激励结构、认知视角三个配套杠杆。四个变量 = 决策环境设计的四个杠杆。

MODULES

逐模块详解

M0 开篇 · 从类型到变量1h
Design + Personality

目标：让高管理解「为什么类型不够，变量才是微调层」，并建立左右箭头的基本语言。

核心知识点：人类图分层（L0 通识 → L4 变量 / PHS → L5 宇宙学）；变量是 fine-tuning，须在活出类型 / 策略 / 权威之后；左箭头 = Design / 身体 = 靠实验（祈使句），右箭头 = Personality / 心智 = 靠观察（陈述句）。

配套素材：cube-matrix-feasibility.html 分层章节 · cube-b2-lecture-notes.html 变量总论

教学活动：破冰——「你最常被误读成什么？」（预演「先否认再定义」）；左右箭头自测。

交付：课程地图卡。

M1 环境 · 决策环境设计2.5h · 副标题主场
身体变量可实验

目标：高管能为自己与团队重设物理 / 远程 / 会议三类决策环境。

核心知识点：环境的本质是神经系统安顿感，不是风水、不是审美；六类环境——洞穴 / 市场 / 厨房 / 山脉 / 山谷 / 海岸；左箭头，给动作。

配套素材（已产出，直接作教材）：cube-b3-detail-pages.html 环境六类 6 张详解页（讲义密度）· cube-b3-oneline-copy.html 环境 6 句核心

教学活动：① 现场环境自评（你是哪类？）② 给自己的工位 / 会议做一处改动 ③ 团队环境审计（谁的结界被破坏了）。

交付：个人环境画像 + 一处 7 日实验。

M2 摄食 · 信息节奏与高管精力2h
身体变量可实验

目标：把「精力管理」从鸡汤变成机制——信息怎么进来、何时进来。

核心知识点：Determination 一律转译为「信息摄入方式与工作节奏」；连续 / 交替两类；六项——食欲 / 品味 / 渴 / 触觉 / 声音 / 光。

合规纪律（本模块不可破） 摄食六项全程不出现任何与饮食、餐饮相关的字——全部落点在节奏。已在 24 项详解页正文 grep 验证零违禁词（固定术语「食欲」为项目名称，非正文）。

配套素材：cube-b3-detail-pages.html 摄食 6 张 · cube-b2-lecture-notes.html 摄食章

教学活动：节奏审计——标出一周里「被塞爆」的时段；设计个人信息摄入窗口（连续型留整块、交替型拆小股）。

交付：周节奏模板。

M3 动机 · 驱动与非物质激励2.5h
心智变量只观察

目标：识别自己的驱动，并学会激励团队（不靠钱）。

核心知识点：动机是心智变量，只能观察、不能改变；六项——恐惧 / 希望 / 欲望 / 需求 / 内疚 / 纯真，每项均有对齐态与错位态；四项带负面色彩的名字须「先否认再定义」。

配套素材：cube-b3-detail-pages.html 动机 6 张 · 冷启动话术包动机相关段落

教学活动：① 写一句「我的点燃句」② 给一位团队成员写一句「激励而非 KPI」的话。

交付：团队激励卡。

M4 视角 · 决策视角与认知校准2.5h
心智变量只观察

目标：识别自己的真实视角与错位滑落，决策前做校准。

核心知识点：六视角（Survival / Possibility / Power / Wanting / Probability / Personal）；必须带「错位项」——只说真实视角是平的，后半句才是客户拍大腿的部分；左聚焦 / 右外围。

配套素材：cube-b3-detail-pages.html 视角 6 张 · cube-b2-lecture-notes.html 视角章

教学活动：决策复盘——上次「滑向错位」是哪次？写一句归位检查点（如「做决定前先问：这安全吗？」）。

交付：个人决策检查清单。

M5 整合 · 个人解码 + 团队变量地图1.5h
整合

目标：把四个变量拼成「我是怎么决策的」全图，并看到团队分布。

配套素材：小程序 B3 变量计算器（四变量同时呈现于结果页）· 团队变量地图画布

教学活动：两两互读详解页 + 团队变量分布图（匿名绘制，看谁在边缘 / 谁在中心 / 谁需要安静）。

交付：个人变量解码报告（小程序一键导出）。

M6 B 端落地 · 从洞察到组织诊断1h
B 端

目标：让 HR / OD 看到变量如何变成组织诊断工具——这是课程真正的商业落点。

核心知识点：四变量 → 组织语言映射（环境→空间与远程配置、动机→激励设计、视角→沟通风格、摄食→工作节奏）；定价纪律：锚定高管教练 / 组织咨询 ¥3,000–10,000 / 次（来自可研对标）；不做 C 端独立开课。

配套素材：cube-matrix-feasibility.html B 端结论 · cube-b3-miniprogram-spec.html · cube-matrix-b2-playbook.html · B 端诊断一页纸

教学活动：用一家真实公司做变量诊断沙盘（环境审计 → 节奏诊断 → 激励匹配 → 视角校准）。

交付：B 端诊断框架一页纸。

DISCIPLINE

教学纪律（贯穿全课）

先否认，再定义
动机四项（恐惧 / 内疚 / 欲望 / 需求）名字自带误解，必须先替客户挡掉误解，他才听得进后面。破折号前要干脆，不留余地。
身体给动作 · 心智给看见
环境 / 摄食用祈使句（「把周三上午空出来」）；动机 / 视角用陈述句（「您会被破损处吸引」），绝不对方心智变量提「你应该改」。
不谈饮食 / 命理 / 健康
摄食只谈节奏；不给医疗、心理、营养建议。
变量是微调，设准入门槛
明确告知这是「体验级」而非「专业解读」；Ra 明言变量须在活出类型之后探索，本课程作为入门展示级精度。
