关于「嘉名」古法姓名能量

为什么不做五格？市面通行的"三才五格 81 数理"并非中国传统古法，而是 1918 年日本学者熊崎健翁以"数理学"开创，1936 年由白玉光（白惠文）传入台湾，90 年代随两岸文化交流风靡大陆。它把姓名按《康熙字典》笔画拆成"天格 / 人格 / 地格 / 总格 / 外格"，对照 81 诱导数理吉凶表判运势，常被正统命理圈批评为：

  • 机械套数字，割裂汉字"音·形·义"的整体性；
  • 简体 / 繁体 / 异体计算结果完全不同；
  • "李刚死""张杀死"能打 95 分，"朱元璋"仅 60 分，被讥为无稽。

五格之前，老祖宗的十大姓名分析方法

中国传统姓名智慧核心不是"算笔画吉凶"，而是"名以正体，字以表德"——礼制、哲学、占卜、音韵、文字学的综合。

古法体系核心要义与史证
八字五行补益唐代李虚中创八字术，宋代徐子平完善。审五行旺衰、取喜用神，以名字补益命局。朱熹家族按五行相生排辈取名即为例证。
易经卦象命名姓笔画为上卦、名笔画为下卦，组成六十四卦取吉。陆羽字鸿渐取《渐卦》；乾隆年号取乾卦"天养万物"。
音韵 / 音律法讲究平仄协调、声母韵母错落、避不良谐音。《乐记》："凡音之起，由人心生也。"
字形 / 六书法偏旁部首自带五行，忌结构单调、肥瘦失衡。五格只数笔画、完全忽略结构美学。
字义 / 典故法"名不正则言不顺"。男参《楚辞》、女取《诗经》，或《论语》《孟子》《诫子书》。
生肖宜忌法生肖配地支，察冲刑害。属鼠避"午（马）"字根；属龙宜"日、月、星、辰"字根。
避讳礼制法避长辈讳、君王讳、先贤讳；"名"与"字"意义相联，如诸葛亮名亮字孔明。
辈分字派宗族定"字派诗"，每辈固定一字，既别长幼、续宗脉，也寄托家风。
测字 / 拆字占卜拆字形、观意象以占吉凶，属姓名占卜的古法支脉。
阴阳协调法天干地支、五行分阴阳。八字阴阳失衡者，以名字气场补救。

核心决策：还有没有必要新做一个姓名工具？

如果做"又一个五格+八字起名工具"——没必要。市场高度饱和，获客极难，喜用神程序化计算也被专业命理师诟病。

但存在两个真实的差异化蓝海：

  • 古法本源回归：把易经卦象命名、六书字形五行、音韵学严谨模型、避讳礼制、名与字相应做成体系化、可解释的工具，几乎空白。
