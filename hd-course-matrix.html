Course Matrix · M0–M10 Overview

《人类图领导力》课程矩阵速览

M0 开篇 → M10 毕业项目，11 个模块横跨四级认证 HD-L1~L4。

每一行都对应「训练目标 + HD 知识点 + 领导力落点」。

使用建议：本速览是「蓝图第 3 节」的独立卡片化版本——可作为招生彩页、学习路径地图、模块选择器单独打印 / 转发，也可点上方链接切回蓝图看每个模块的"训练练习 · 时长 · 评估"完整设计。
开篇 · L0— 文化入口（不碰 HD 术语，纯东方智慧降低陌生感）
模块主题级别核心落点
M0易经智慧与领导之道开篇三易（变易 / 简易 / 不易）· 乾坤 · 时中 — 东方领导哲学入门；为后续"类型=你的领导本色"埋伏笔。
L1 · 启航— 读懂自己的设计
模块主题级别核心落点
M1认识你的设计：类型与策略L15 种类型对应领导本色：显示者（发起破局）/ 生产者（执行持续）/ 显示生产者 / 投射者（顾问赋能）/ 反映者（感知节律）。
M2内在权威与决策力L17 类权威（情绪 / 荐骨 / 脾 / 自我 / G / 环境 / 无权威）× 决策节奏；时中 / 持经达变 → 决策质量。
M3人生角色与领导位势L1·L212 种 Profile（1/3 烈士 · 2/4 隐士 · 4/6 楷模 …）→ 你在组织的位与势。
L2 · 实践— 带好你的团队
模块主题级别核心落点
M4能量中心与领导盲区L29 大中心定义 / 未定义 → 精力管理；未定义 G 中心 = 共情雷达也是耗竭点。
M5非我主题与抗倦怠L2显化者=愤怒 / 生成者=挫败 / 投射者=苦涩 / 反映者=失望；亢龙有悔 → 可持续领导节奏。
M6通道闸门与天赋领导L236 条通道 / 闸门 → 领导优势变现；"各正性命"让对的人在对的位置发光。
L3 · 精通— 团队设计地图
模块主题级别核心落点
M7团队设计地图L3类型排布 · 按类型授权 · 会议设计 → 团队设计地图（企业端高客单钩子）。
M8组织设计与文化L3BG5 / OC16 轻量应用层（深讲留给教练课）—— 组织也有类型。
M9真实领导与仆人式领导L3·L4谦卦 · 修己安人 · 德位相当 → 真实 / 仆人式领导；六爻皆吉的谦是管理本质。
L4 · 导师— 毕业项目 / 顶点交付
模块主题级别核心落点
M10毕业项目：设计驱动领导实验L48 周真实组织实验 + 路演答辩 + 同伴评审；前测 / 后测数据证明"图真的有用"。
逻辑闭环：开篇 M0（文化桥）→ L1 自我觉察（M1-M3）→ L2 团队应用（M4-M6）→ L3 组织设计（M7-M9）→ L4 毕业交卷（M10）。遵循"觉察 → 应用 → 组织 → 认证"递进，每一级都可独立成课，也可串成完整进阶。
