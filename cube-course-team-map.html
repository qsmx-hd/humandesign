HOW TO USE

怎么用这张画布

匿名优先 首次绘制建议用代号（A 总 / B 总）而非真名，降低防御；在「看分布」阶段人人平等。环境决定物理空间、摄食决定信息节奏、动机决定激励话术、视角决定沟通与决策盲区——四层叠加，就是团队的「决策操作系统」。
  1. 在下方录入每位成员的四变量（环境 / 摄食节奏 / 动机 / 视角）。
  2. 画布自动把成员按「环境六类」集群到对应区域，并标出安静区 / 中心区 / 边缘区。
  3. 下方统计与洞察卡给出：谁需要安静、团队主驱动、决策盲区（缺哪类视角）。
  4. 导出结论用于 M5「团队变量分布图」交付，或带入 M6 做 B 端诊断。
