THE DUAL HELIX

人类图是地图，开心是打开心扉

市面上的课程大多止步于「知道」：知道自己是生产者、知道策略是等待回应。
但知道设计，不等于活出设计；活出设计，心才会真正打开——那才是持续的开心。

知 · 人类图设计蓝图

📐 它告诉你「你是谁」

  • 类型与策略：你与世界正确互动的开关
  • 内在权威：身体的决策系统（荐骨 / 情绪 / 脾…）
  • 九大中心：定义 vs 开放（开放=条件化区域）
  • 非我主题：偏离设计时的痛苦信号（挫败 / 愤怒 / 苦涩 / 失望）
  • 签名：活出设计时的满足信号（满足 / 平静 / 成功 / 喜悦）
行 · 开心经营体系

🗝️ 它教你「如何打开心扉」

  • 3M 模型：物质快乐 → 心智安乐 → 心性极乐
  • 四度修炼：高·广·深·远，重练认知境界
  • 觉止 STOP：停一下，让真实权威出来
  • 见事情 BAC：把「事」与「情」分开，不为情绪所困
  • 转见 / 转心：与过去和解、与未来做朋友
🌉 开心，就是让人类图从「知识」变成「体验」的那一座桥——活出设计，心自然打开

CORE MODEL

类型 × 开心转化 · 心关上 → 心打开

人类图的非我主题，就是「心门关上、不开心」的状态；签名，就是「心打开、开心」的状态。
当痛苦信号升起，用开心经营的方法，把它转回设计。

LEARNING PATH

两条学习路径

开心之道不是听明白的，是练出来的。给自己一个小目标，先坚持起来。

🌤️ 21 天开心入门

每天 10–15 分钟 · 身体·心智·心性三层打卡
  • 建立「每日打开心扉」的基本节奏
  • 掌握觉止 STOP，能在情绪里停一下
  • 认出自己的非我主题与触发点
  • 完成 21 篇开心觉察日记
  • 体验「心打开，情绪自然少」

🌳 100 天三层扎根

把练习变成呼吸 · 口诀：「自己最差，老实听话」
  • 从「工具式修行」走向「在生活中练习」
  • 知识→智慧四步开始稳定显现
  • 在等待 / 告知 / 回应中自然对齐设计
  • 关系、情绪、困境中不被轻易带走
  • 迈向「开心即生活，生活即开心」
